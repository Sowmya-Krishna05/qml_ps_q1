# QFF 2026 · Phase 2 · QML track

**Problem statement: PS-Q1 — ECG heartbeat classification (same PS as Phase 1).**
**Common tasks: Task A (Bell state fidelity) and Task B (Processor D design + QFT-3 benchmark).**
Noise model: organiser `QFF2026-v2`, unchanged, every noisy circuit transpiled to the fully-noised basis `rx, ry, rz, cx`.

A hybrid variational quantum classifier (angle-encoded PCA features → trainable RY·RZ → ring of CX → parity read-out → trainable scale/bias) is compared with tuned classical baselines, evaluated ideal and under the organiser noise (with read-out mitigation, threshold re-calibration and ZNE as optional extras), ablated, and run on a self-designed Processor D. The full write-up, with every number generated by the notebook, is in **[`results.md`](results.md)**.

## Reproduce (clean clone)

```bash
python3 -m venv qml-env                      # Python 3.11, 3.12 or 3.13
source qml-env/bin/activate                  # Windows: qml-env\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt              # exact pinned versions (kit v3)
python tests/test_sim.py                     # optional: simulator unit test (~1 s)
jupyter nbconvert --to notebook --execute --inplace solution.ipynb  
```

The notebook regenerates `predictions_q1.csv`, `processor_d_config.json` (with the official `benchmark_results`), `results.md`, `pip_freeze.txt`, the pip-freeze block at the bottom of this file, and everything in `results/`.
Afterwards the two official checks can be re-run by hand:

```bash
python tools/validate_predictions.py q1 predictions_q1.csv
python benchmark/qff_qml_benchmark.py processor_d_config.json     # must print the same benchmark_results, no WARNING
```

`solution.ipynb` loads the design-selection and ablation tables from `results/model_selection.csv` / `results/ablation.csv`
(generated with `python scripts/run_sweeps.py`, ~25 min on 2 cores, validation data only). Set `RUN_SWEEPS = True` in the notebook's first cell to recompute them inside the notebook instead.
All seeds are fixed (global 42; model seeds 0, 1, 2; Aer and transpiler seed 42).

## Notes for judges

* Training and the design sweeps use an exact NumPy simulator for speed. The notebook asserts that it agrees with Qiskit's `Statevector` to < 1e-8 on 25 validation samples. **All reported noisy numbers come from qiskit-aer with the unchanged organiser model**; the "dev-noisy" ablation columns are an exact density-matrix replica of that model and are labelled as such.
* No scaler, PCA, feature selection, hyper-parameter or threshold was fitted on test data; validation data is used for model selection and (cross-validated) threshold re-calibration only.
* The data is almost linearly separable (a logistic regression is the organisers' reference at macro-F1 1.000), so the report concentrates on what the quantum circuit costs and contributes rather than on the headline score.
